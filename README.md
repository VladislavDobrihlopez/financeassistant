## FinanceApp - менеджер транзакций, доходов, расходов

## 🔧 Стек технологий

- **Kotlin**
- **Jetpack Compose** (UI)
- **Decompose** (platform aware навигация)
- **MVIKotlin** (MVI-подход, архитектура Intent / Action / Message / State / Label (сайд-эффекты))
- (Intent, Action) -> CoroutineExecutor -> dispatch(Message), publish(Label) -> Reducer
- **Dagger (Hilt / AssistedInject)**
- **Coroutines / Flow**
- **Retrofit / Gson** 
- **Kotlinx serialization**
